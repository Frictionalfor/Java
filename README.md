# Java Learning Journey

> Frictional's comprehensive notes and practice programs while learning Java from basics to advanced concepts.

## About This Repository

This repository contains my Java learning journey, organized topic by topic. Each section includes concise notes and hands-on programs to reinforce concepts. It also includes college practicals (numbered `practical2.java` through `practical24.java`), a Flask-based website for viewing and editing notes, and reference PDFs.

## How to Use

### Command Line

1. Clone the repository
2. Navigate to any topic folder
3. Read the notes in `Notes.md` or individual topic files
4. Compile and run the Java programs to practice

```bash
javac practical2.java
java practical2
```

### Website (Recommended)

A web interface is included for easy viewing and editing:

```bash
cd website
./run.sh
# Or
python3 app.py
```

Then open http://localhost:5000 in your browser.

Features:

- Browse all notes in sidebar
- View formatted markdown
- Edit notes directly in browser
- Save changes instantly
- Dark theme for comfortable reading
