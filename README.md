# Java Learning Journey

> Ferb's comprehensive notes and practice programs while learning Java from basics to advanced concepts.

## About This Repository

This repository contains my Java learning journey, organized topic by topic. Each section includes concise notes and hands-on programs to reinforce concepts.

## Topics Covered

### Core Basics
- JDK, JRE, and JVM architecture
- IDE Setup
- Basic Syntax and code structure
- Primitive Data Types
- Variables and naming conventions
- Operators (Arithmetic, Relational, Logical, Assignment)
- Conditional Statements (if, else if, else, switch)
- Loops (for, while, do-while, enhanced for)

### Intermediate Core Java
- Arrays (Single and Multi-dimensional)
- String Handling (Immutability, String, StringBuilder, StringBuffer)
- Methods (Parameters, return types, overloading)
- Classes and Objects
- Access Modifiers
- Keywords (this, super, static, final)
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Package Management
- Exception Handling

### Advanced Java Foundations
- Java Collections Framework
- Generics
- Lambda Expressions
- Stream API
- Built-in Functional Interfaces
- Optional Class
- File I/O
- Multithreading
- Concurrency Utilities

### Advanced & Enterprise Level
- Memory Management
- JDBC
- Build Tools
- Version Control
- Unit Testing
- Spring Boot Framework

## How to Use

### Command Line
1. Clone the repository
2. Navigate to any topic folder
3. Read the notes in `Notes.md` or individual topic files
4. Run the Java programs to practice

### Website (Recommended)
A web interface is included for easy viewing and editing:

```bash
cd website
./run.sh
# Or
python3 app.py
```

Then open http://localhost:5000 in your browser.

Features:
- Browse all notes in sidebar
- View formatted markdown
- Edit notes directly in browser
- Save changes instantly
- Dark theme for comfortable reading
