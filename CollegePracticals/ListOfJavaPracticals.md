# List of Java Practicals

## Rules
- No comments and code should be simple and easy
- File name should be `practical(number of the practical).java`

## Practicals

### Practical 2
**Aim:** Write program to demonstrate use of if statements (all forms of if statement)

### Practical 3
**Aim:** Write programs to demonstrate use of Switch Case Statement

### Practical 4
**Aim:** Write program to demonstrate use of different types of loops (for, while and Do while)

### Practical 5
**Aim:** Write program for implementing methods of: i) String class and ii) String buffer class

### Practical 6
**Aim:** Write program to demonstrate use of array

### Practical 7
**Aim:** Write program to demonstrate use of vectors

### Practical 8
**Aim:** Write a program for implementation of method overloading

### Practical 9
**Aim:** Write a program for implementation of Final variables, methods, classes

### Practical 10
**Aim:** Write a program for implementation of dynamic method dispatch

### Practical 11
**Aim:** Write a program using wrapper class to convert primitive data type into object

### Practical 12
**Aim:** Write program using wrapper class to convert object into primitive datatype

### Practical 13
**Aim:** Develop program for implementation of interface

### Practical 14
**Aim:** Write program to demonstrate use of built-in packages

### Practical 15
**Aim:** Write program to demonstrate use of user-defined packages

### Practical 16
**Aim:** Write program for implementation of in-built and user-defined exception using try, catch and finally block and throw and throws clause

### Practical 17
**Aim:** Write program using multithreading

### Practical 18
**Aim:** Program using collection interface

### Practical 19
**Aim:** Write a program to perform file operations - read, write, copy content from one file to another, write bytes using FileOutputStream and read bytes using FileInputStream

### Practical 20
**Aim:** Write a program using AWT to create a simple GUI with a label, text field, button and display greeting message on button click

### Practical 21
**Aim:** Write program to create a menu bar with various menu items and sub menu items

### Practical 22
**Aim:** Write a program to demonstrate the use of border layout. The layout shows four buttons at four sides with captions "left", "right", "top" and "bottom" using AWT components

### Practical 23
**Aim:** Write program to design a calculator to demonstrate the use of grid layout using AWT

### Practical 24
**Aim:** Write a program using JDBC to connect to any database and retrieve all records from the students_info table
