# Java Notes Website

A simple web interface to view and edit Java study notes.

## Features

- Browse all markdown notes in sidebar
- View rendered markdown with syntax highlighting
- Edit notes directly in browser
- Save changes back to files
- Dark theme with black background and white text
- Keyboard shortcuts (Ctrl+S to save, Escape to cancel)

## Setup

1. Install Python 3
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the server:
   ```bash
   python app.py
   ```
4. Open browser and go to: http://localhost:5000

## Usage

- **Click** any file in sidebar to view it
- Click **Edit** button to edit the file
- Make changes and click **Save** or press **Ctrl+S**
- Click **Cancel** or press **Escape** to discard changes

## Color Scheme

- Background: Black (#0a0a0a)
- Sidebar: Dark gray (#111111)
- Text: White (#ffffff)
- Accent: Solid green (#00ff88)
