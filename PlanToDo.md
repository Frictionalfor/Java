## Core Basics

* JDK, JRE, and JVM architecture
* IDE Setup (IntelliJ IDEA, Eclipse, or VS Code)
* Basic Syntax and code structure
* Primitive Data Types (int, float, double, char, boolean)
* Variables and naming conventions
* Operators (Arithmetic, Relational, Logical, Assignment)
* Conditional Statements (if, else if, else, switch)
* Loops (for, while, do-while, enhanced for)

## Intermediate Core Java

* Arrays (Single and Multi-dimensional)
* String Handling (Immutability, String, StringBuilder, StringBuffer)
* Methods (Parameters, return types, overloading)
* Classes and Objects (State, behavior, and instantiation)
* Access Modifiers (private, default, protected, public)
* Keywords (this, super, static, final)
* Encapsulation (Getters and setters)
* Inheritance (extends keyword, method overriding)
* Polymorphism (Compile-time vs. Runtime)
* Abstraction (Abstract classes and Interfaces)
* Package Management (Importing and organizing code)
* Exception Handling (try, catch, finally, throw, throws, Custom Exceptions)

## Advanced Java Foundations

* Java Collections Framework (List, Set, Map, Queue implementations)
* Generics (Type safety, bounded type parameters)
* Lambda Expressions (Functional programming syntax)
* Stream API (Filtering, mapping, and reducing data collections)
* Built-in Functional Interfaces (Predicate, Consumer, Supplier, Function)
* Optional Class (Null pointer prevention)
* File I/O (Reading/writing via java.io and modern java.nio)
* Multithreading (Thread class, Runnable interface)
* Concurrency Utilities (Thread pools, ExecutorService, synchronization, locks)

## Advanced & Enterprise Level

* Memory Management (Heap vs. Stack, Garbage Collection tuning)
* JDBC (Java Database Connectivity, SQL integration)
* Build Tools (Dependency management with Maven or Gradle)
* Version Control (Git and GitHub workflows)
* Unit Testing (Writing test cases with JUnit and Mockito)
* Spring Boot Framework (Dependency Injection, building REST APIs, Microservices)
